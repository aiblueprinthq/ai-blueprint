# Support

## Start with the documentation

The [AI Blueprint documentation](https://ai-blueprint.dev/docs/) covers setup,
updates, commands, file behavior, and troubleshooting.

## Ask a usage question

Use the
[usage question form](https://github.com/bradtraversy/ai-blueprint/issues/new?template=question.yml)
after checking the documentation and existing issues. Include the installed
version, adapter, environment, and the specific step that blocked you.

## Report a bug

Use the
[bug report form](https://github.com/bradtraversy/ai-blueprint/issues/new?template=bug_report.yml)
for reproducible installer or workflow problems.

## Request a feature

Use the
[feature request form](https://github.com/bradtraversy/ai-blueprint/issues/new?template=feature_request.yml)
for changes to the reusable Blueprint workflow or installer. App-specific
feature requests are out of scope.

## Report a vulnerability

Follow [SECURITY.md](SECURITY.md). Do not disclose a suspected vulnerability in
a public issue.
